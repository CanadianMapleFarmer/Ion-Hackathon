# TODO App UI Design

## HTML Structure

1. **Header**
   - Title: "TODO App"

2. **Main Section**
   - **Input Field** for adding new todo
   - **Add Button** to submit new todo

3. **Todo List Section**
   - List of todos with each having:
     - Checkbox to mark complete
     - Text (description of the todo)
     - Edit Button
     - Delete Button

## Basic CSS Styles

1. **Layout**
   - Flexbox/Grid for layout management

2. **Typography**
   - Font selection and sizing for readability

3. **Colors and Themes**
   - Consistent theming with light and dark mode option

4. **Responsive Design**
   - Ensure usability across devices (desktop, tablet, mobile)

## JavaScript Functions

1. **Add Todo**: Capture input and update list
2. **Edit Todo**: Modify existing todo
3. **Delete Todo**: Remove selected todo
4. **Toggle Completion**: Mark/unmark todo as complete
